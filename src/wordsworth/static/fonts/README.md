# Lettertypen

Zelf gehost, niet van een CDN. Dit is het scherm waar wordsworth zijn
soevereiniteitsclaim demonstreert en ook het scherm waar mensen in de
netwerkinspector kijken; letters ophalen bij Google weerlegt die claim daar
onmiddellijk, wat de omringende tekst ook zegt.

Alleen de **latijnse** subsets, uit Google Fonts (2026-09-17). De volledige set
was 28 bestanden met Cyrillisch, Grieks en Vietnamees erbij; dit zijn er negen,
samen 224 KB.

De SIL Open Font License staat verspreiding toe, óók gebundeld in software,
zolang de licentietekst meereist en de Reserved Font Names niet worden hergebruikt
voor gewijzigde versies. Deze bestanden zijn ongewijzigd overgenomen, dus dat
laatste speelt niet. De tekst staat hiernaast per familie en één keer centraal in
`LICENSES/OFL-1.1.txt`.

OFL is een permissieve licentie voor de fonts zelf en werkt niet door op de
software die ze insluit — de MIT-invariant van dit project blijft dus staan.
